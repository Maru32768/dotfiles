# PR運用

- GitHubのPRを作るときは、Assigneesに自分を設定する(`gh pr create --assignee @me`)
- レビューコメントへの返信は、投稿する前に必ず確認を取る。対応方針や下書きが承認済みでも、投稿する本文そのものを見せて確認を取る。AIのレビューへの返信は、確認を取らずに投稿してよい
- 直したことを伝える返信は、何をどう直したかの1文だけにする。理由、付随する変更、確かめたことは、聞かれていなければ書かない
- 直したコミットは、短縮SHAではなく、PR上のコミットのURL(`https://github.com/<owner>/<repo>/pull/<PR>/commits/<SHA>`)で示す。URLは`[短縮SHA](URL)`のリンクにする。URLの直後に全角の「）」や「。」を続けると、GitHubの自動リンクがそれもURLに含めて、リンクが壊れる
